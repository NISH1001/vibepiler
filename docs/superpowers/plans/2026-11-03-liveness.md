# Liveness Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A `liveness` pass that finds the leftovers inside function bodies with a real backward dataflow analysis, a `Liveness` metric in [0, 1] printed beside bloat everywhere bloat prints, and a `Metric` base that `Bloat` and `Liveness` share.

**Architecture:** Each language adapter classifies a statement into one of six flow shapes (plain, branch, loop, try, with, jump) with its definitions and uses; a language-agnostic engine folds those backward to a fixpoint and reports dead stores, unused parameters, unreachable statements and dead branches. The pass turns the engine's answers plus the existing reachability verdicts into findings and into a per-unit `Liveness` value, stored like bloat is stored. Backends, the gate and the baseline iterate a registry of metrics instead of naming bloat.

**Tech Stack:** Python 3.12, tree-sitter via `tree-sitter-language-pack`, dataclasses, pytest; ruff (dev only) as the oracle for the Python findings.

**Spec:** `docs/superpowers/specs/2026-11-03-liveness-design.md`

## Global Constraints

- No new runtime dependency; ruff goes in the `dev` group of `pyproject.toml` only.
- Deterministic: findings sorted by (file, line, code); same input, same output.
- Existing bloat numbers, `ir.json` keys (`attrs.bloat`, `metrics.bloat_score`) and CLI flags keep working unchanged. `Bloat` values on the fixture are byte-identical before and after.
- When the analysis is unsure, a definition is live. Unknown statement types read everything they contain and define nothing.
- Names follow the compiler metaphor: pass `liveness`, analogue "liveness analysis / dead-store elimination", codes `dead-store`, `unused-param`, `unused-attribute`, `unreachable-code`, `dead-branch`.
- No fold of liveness into the bloat formula on this branch.
- Branch: `feature/liveness`. Commit after every task.

## Review Focus

- A `self.x` store inside a method whose class has an unresolved base, read nowhere by name: must not be reported (`unused-attribute` exemption), since the framework may read it. Test in Task 6.
- A parameter read only inside a nested closure or lambda: must count as read, never `unused-param`. Test in Task 4.
- A store before a `try` whose only read is in an `except` handler: must be live. Test in Task 4.
- A loop whose body stores a name at the end and reads it at the top of the next iteration (`prev = cur` patterns): the store must be live, not "never read". Test in Task 4.
- A `for i, x in ...` where only `x` is read: no `dead-store` on `i` (destructuring sibling rule), and `for _ in range(3)` never reported. Test in Task 6.

**Interfaces:**
- Produces, in `frontend/flow.py`:
  ```python
  DefKind = Literal["param", "local", "attribute", "destructure", "loop", "with", "except"]

  @dataclass(slots=True)
  class Def:
      name: str
      node: Node                  # the statement (or parameter node) that makes the definition
      kind: DefKind
      group: int = 0              # destructuring siblings share a group id; 0 = none
      rhs_has_call: bool = False  # the right-hand side contains a call, await or yield
      attr_of: str | None = None  # "self" / "this" for an attribute store

  @dataclass(slots=True)
  class Plain:  node: Node; defs: list[Def]; uses: set[str]
  @dataclass(slots=True)
  class Branch: node: Node; uses: set[str]; arms: list[tuple[Node, list[Node]]]; has_else: bool; constant: bool | None
  @dataclass(slots=True)
  class Loop:   node: Node; defs: list[Def]; uses: set[str]; body: list[Node]; else_body: list[Node]; constant: bool | None; label: str | None
  @dataclass(slots=True)
  class Try:    node: Node; body: list[Node]; handlers: list[tuple[list[Def], list[Node]]]; else_body: list[Node]; final: list[Node]
  @dataclass(slots=True)
  class With:   node: Node; defs: list[Def]; uses: set[str]; body: list[Node]
  @dataclass(slots=True)
  class Jump:   node: Node; kind: Literal["return", "raise", "break", "continue"]; uses: set[str]; label: str | None
  Flow = Plain | Branch | Loop | Try | With | Jump
  ```
  `Branch.arms` lists `(clause node, statements)` in source order, the `else` last when `has_else`. `constant` is the literal value of the first condition (`True`/`False`), `None` otherwise or for `TYPE_CHECKING` / `__debug__`. `uses` are the names read by the condition(s) / iterable / context expression. A `Loop.defs` holds the loop target(s) with `kind="loop"` (one `group` for a tuple target). A `Try` handler's defs hold `except E as e` with `kind="except"`.
- Produces, on `LanguageSpec` (base.py), with these defaults:
  ```python
  def classify(self, stmt: Node, sf: SourceFile) -> Flow:          # default: Plain(stmt, [], self.names_in(stmt, sf))
  def names_in(self, node: Node, sf: SourceFile) -> set[str]:      # default: every identifier text under node
  def function_params(self, def_node: Node, sf: SourceFile) -> list[tuple[str, str]]:  # (name, "self" | "plain" | "rest"), positional order; default []
  def captured_names(self, def_node: Node, sf: SourceFile) -> set[str]:   # names read inside nested defs and lambdas; default set()
  def has_dynamic_scope(self, def_node: Node, sf: SourceFile) -> bool:    # default False
  ```
  Python: `Plain` covers `expression_statement` (assignment, augmented assignment, walrus inside, calls), `delete_statement` (uses), `global_statement`/`nonlocal_statement` (a `Plain` with a `Def` of kind `"local"` and `name` prefixed `"global:"`, which the engine treats as an exemption marker; see Task 4), `pass`, `assert`, nested `function_definition`/`class_definition` (uses = captured reads, no defs). `Branch`: `if_statement` with `elif_clause`/`else_clause`, `match_statement` (each `case_clause` is an arm; v1 treats pattern captures as uses, not definitions). `Loop`: `for_statement`, `while_statement`. `Try`: `try_statement`. `With`: `with_statement`. `Jump`: `return_statement`, `raise_statement`, `break_statement`, `continue_statement`. Augmented assignment `x += 1`: `uses` includes `x`, `defs` has `x` with `rhs_has_call` as computed. Attribute target `self.x = ...`: a `Def(kind="attribute", attr_of="self")` and `uses` includes `self`. Subscript/attribute targets other than `self.x`/`cls.x`: uses only. Tuple/list targets: one `Def` per name with a shared `group`. `has_dynamic_scope`: any call to `locals`, `vars`, `globals`, `eval`, `exec` in the body.

### Task 4: The dataflow engine

**Files:**
- Create: `src/vibepiler/passes/dataflow.py`
- Test: `tests/test_dataflow.py`

**Interfaces:**
- Consumes: `LanguageSpec.classify`, `function_params`, `captured_names`, `has_dynamic_scope`, `body_statements`; the `Flow` shapes.
- Produces:
  ```python
  @dataclass(slots=True)
  class Store:
      d: Def
      live: bool
      overwritten_at: int | None     # line of the next store to the same name when this one is dead and one exists

  @dataclass(slots=True)
  class FunctionLiveness:
      params: list[tuple[str, str, bool]]      # (name, kind, read): read = live at function entry
      stores: list[Store]                      # every Def the body makes, in source order (locals, attributes, destructure, loop, with, except)
      unreachable: list[tuple[Node, Node]]     # (first dead statement, last dead statement) per block
      dead_branches: list[Node]                # the clause/body node of each dead arm
      skipped: bool                            # dynamic scope: params and stores are empty

  def analyze(def_node: Node, spec: LanguageSpec, sf: SourceFile) -> FunctionLiveness
  ```
  A `Def` whose `name` starts with `"global:"` (Task 2's marker for `global`/`nonlocal`) is not a store; its bare name is removed from every reported store.

  The algorithm, backward over the flow shapes, with `captured = spec.captured_names(...)` unioned into `out` before every recording:
  ```
  block(stmts, out, loops) -> in:      fold stmts from last to first through stmt(); also scan forward: after the first stmt that
                                        terminates(), record (next, last) as unreachable and do not analyse those statements
  stmt(Plain)   -> record each def live iff name ∈ out;  in = uses ∪ (out − {def names})
  stmt(Branch)  -> if constant is True/False: record the dead arm, drop it;  in = uses ∪ ⋃ block(arm) ∪ (out if not has_else)
  stmt(Loop)    -> else_in = block(else_body, out);  head = uses ∪ else_in
                   repeat: body_in = block(body, head, loops + [(label, break=out ∪ else_in, continue=head)])
                           new = uses ∪ else_in ∪ (body_in − target names);  until new == head  (record targets live iff name ∈ body_in)
                   constant False: record body as a dead branch, in = uses ∪ else_in

  params        -> read iff name ∈ block(body, ∅) at entry, or name ∈ captured
  ```
