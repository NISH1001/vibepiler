Parse: every file becomes a syntax tree

tree-sitter parsed each file into a concrete syntax tree. The adapter for its language then walked that tree once and recorded definitions, imports, call sites with their enclosing scope, references and entry-point hints. Click a file to see it in the graph.

Link: names resolved across files

Each module gets a binding table from its imports and definitions. Every call site and reference is then resolved through that table, the enclosing class, and module/class member lookup. Calls whose receiver type is unknown are not guessed; their member names are kept so the passes stay conservative.
